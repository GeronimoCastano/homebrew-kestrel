# Homebrew tap for Kestrel

```sh
brew install GeronimoCastano/kestrel/kestrel
```

That taps `GeronimoCastano/kestrel` and installs the compiler from source at the
latest release tag. For the development branch:

```sh
brew install --HEAD GeronimoCastano/kestrel/kestrel
```

The language lives at <https://github.com/GeronimoCastano/kestrel>.
